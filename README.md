# Online Lawyer Booking System

A web-based Online Lawyer Booking System developed using Django and MySQL.

## Features

- Admin Module
- Lawyer Module
- Client Module
- Lawyer Booking
- Service Management
- Query Management
- Feedback System
- Notifications
- File Upload and Download

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
